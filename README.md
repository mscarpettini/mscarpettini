I study bioinformatics at the University of Buenos Aires. My thesis focused on detecting DNA deletions and duplications, known as copy number variants (CNVs), in exome data. How much does the choice of reference samples change which variants we detect in the same exome?

### What I’m working on

exome-pon is a Python tool I built to select reference samples. It compares read counts across genomic regions and ranks samples by how closely they match the exome I’m analyzing. I included a small example with simulated data to show how two similarity measures can select different controls for the same exome.

## Español

Estudio bioinformática en la Universidad de Buenos Aires. En mi tesis investigué cómo detectar pérdidas y duplicaciones de ADN, conocidas como variantes en el número de copias (CNV). ¿Cuánto cambia lo que detectamos cuando elegimos distintas muestras de referencia para analizar el mismo exoma?

### Qué estoy desarrollando

exome-pon es una herramienta que desarrollé en Python para elegir muestras de referencia. Compara los recuentos de lecturas por región y ordena las muestras según su similitud con el exoma que quiero analizar. Preparé un ejemplo con datos ficticios para mostrar cómo cambia la selección de controles al cambiar la medida de similitud.
